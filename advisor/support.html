Support

Answers to common questions, and how to reach us.

Questions

How do I connect my coding agents?
  1. Open Advisor from its icon in the menu bar (macOS) or the system tray (Windows), and choose Open Advisor.
  2. Go to the Agents tab. It lists each supported agent it finds on your computer: Claude Code, Codex, Copilot CLI, Cursor, and Grok Build.
  3. Read the change it shows for each agent, and click Install hooks to apply it.

Nothing is written until you click. Advisor backs up each file first, next to the original, and only touches its own entries. Your other hooks and settings stay as they were. Start a new session afterwards, and it appears in Advisor.

My sessions don't show up.

Check the Agents tab first. An agent marked Out of date or not set up needs Install hooks again. Then start a new session, or send a prompt in an existing one. Sessions that were already running when Advisor started appear on their next prompt or tool call. Claude Code, Copilot CLI, and Grok Build sessions usually appear right away.

Advisor must be running for sessions to report in. Only one copy runs at a time.

A session stays listed after I closed it.

Agents don't always say goodbye. Closing a terminal window or a crash can end a session without telling Advisor. Advisor clears these on its own for Claude Code and Grok Build. For the others, click the × on its card in the window.

Clicking a session doesn't bring its window forward on my Mac.

Advisor needs your permission to switch windows. Open System Settings → Privacy & Security and turn Advisor on under Accessibility, and under Automation for your terminal or editor. macOS asks the first time Advisor tries each app.

If Advisor already looks allowed under Accessibility but still can't switch windows, the entry may be from an older copy. Select it, remove it with the − button, then quit and reopen Advisor and allow it again.

Which windows can Advisor bring forward on Windows?

Advisor brings forward the window a session runs in, and in Windows Terminal it also selects the session's tab. No permission is needed. If two sessions run in the same window of an editor, such as VS Code, both bring that window forward.

What are the keyboard shortcuts?

Sessions 1 to 9 each have a shortcut that brings their window forward from any app: ⌃⌥1 to ⌃⌥9 on a Mac, and Alt+Shift+1 to 9 on Windows. The same keys with 0 open Advisor's menu, which shows each session's number. If another app already uses one of these, Advisor skips it. Turn them all off with Global shortcuts at the bottom of the window.

How do I change a session's number?

Click the number on its card and pick another. The session swaps places with whichever session had that number.

What are local AI summaries?

Normally each card shows the first line of the session's latest prompt. Turn on Local AI summaries at the bottom of the window, and a model running on your computer writes a one-line title instead. On a Mac with Apple Intelligence, it can use Apple's on-device model. Otherwise, Advisor downloads a small model (about 490 MB) the first time, with progress shown beside the toggle. Your prompts never leave your computer either way.

Can Advisor start when I sign in to Windows?

Yes, in the version from the Microsoft Store. Click Advisor's tray icon and check Start at Login. You can also turn it on or off in Settings → Apps → Startup, where it's listed as AI1 Advisor. If you turned it off there, the menu says so, and only Settings can turn it back on.

Where is Advisor when its window is closed?

Closing the window only hides it. Advisor keeps running in the menu bar on a Mac, or in the system tray on Windows. On Windows, the tray icon might be in the overflow area behind the ^ arrow. Hover over it to see how many sessions are running and how many need you. To quit, choose Quit Advisor from its menu.

Do I need the QMK keyboard?

No. Everything works without one. With a supported keyboard running Advisor's QMK firmware, one key per session lights in the same colors, and pressing it brings that session's window forward.

How do I remove Advisor?

In the Agents tab, click Remove hooks for each agent. Then quit Advisor and uninstall it. On a Mac, drag it to the Trash. On Windows, uninstall it from Settings → Apps. Last, delete the .ai1-advisor folder in your home folder, which holds Advisor's settings, log, and model. See the privacy policy for what's in it.

Contact

Found a bug, or have a question or idea? Open an issue on GitHub (a free GitHub account is required). Issues are public, so please leave out prompts, file paths, and anything else private.

Open an issue on GitHub

Include your Advisor version (shown in its menu, under Open Advisor), your macOS or Windows version, which agent the session was in, and what you expected to happen.
