See every AI session on a key.

Advisor listens to your coding agents and lights one key per session. The color is what that session is doing. Press the key and its window comes forward.

In the app

Grouped by agent

Sessions sit together by agent, each with its state, how long it has been in it, and a one-line summary of the prompt.

Live activity

While a tool runs, the session shows which tool and for how long.

Click to focus

Click a session to bring its window forward. Click its key number to move it to another key.

On your Mac

  1. Open the disk image and drag Advisor to Applications.
  2. Open Advisor and allow the download prompt. Grant Accessibility and Automation when macOS asks. A key press needs them to raise the right window.
  3. The Agents view lists each coding agent it finds. You review the hook change, and nothing is written until you apply it.
  4. Connect the keyboard with a USB-C cable that carries data. Charge-only cables will not light the keys.

Agents that report in

Advisor reads each agent's own hooks. A session can belong to Terminal, VS Code, or IntelliJ.

  • Claude Code
  • Codex
  • Copilot CLI
  • Cursor
  • Grok Build
